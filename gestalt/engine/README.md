## goal

ziel ist, die engine auf verschiedene arten nutzen zu können:

### by `<app-root>`

```html
<app-root>
  ...
  <div
    gestalt-flow='grid 3x3'
    gestalt-typo='uppercase'
  >
    ...
  </div>
  ...
</app-root>
```

### by css

```css
div {
  --gestalt-flow: grid 3x3;
  --gestalt-typo: uppercase;
}
```
